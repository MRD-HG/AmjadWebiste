# Post-deployment checklist

- [ ] HTTPS is forced; cookies are Secure/HttpOnly/SameSite and login throttling works.
- [ ] `admin/storage`, `admin/includes`, `admin/bin`, credentials, revisions, imports, and logs return 403/404 publicly.
- [ ] No public backup archive such as `admin.zip` exists.
- [ ] Home, about, services, programs, news, shop, contact, and Skhirat memory load at 390, 768, 1024, and 1440 px.
- [ ] Arabic RTL, French LTR, and English LTR switch without losing CMS content.
- [ ] Hero edit, image replacement, program card/detail, new news search/filter/modal/hash, product selection, and memory/gallery placement work.
- [ ] Draft and archived records are absent publicly; unavailable projections leave usable static content.
- [ ] Prayer and zakat tools still work without storing financial input; Eco-School tabs/hotspots/3D fallback remain useful.
- [ ] Upload rejects executable, spoofed, oversized, and unsafe-dimension files; in-use media cannot be archived.
- [ ] Revision restore regenerates the expected public content.
- [ ] Browser console has no application errors; keyboard focus, labels, modal Escape, contrast, and reduced motion are checked.
- [ ] Backup location, owner approval, release ZIP hash, and rollback contact are recorded.
